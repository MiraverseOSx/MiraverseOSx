# Decision-register alignment in the local game

This update implements the confirmed structural rules while retaining existing saves, payout receipts and established costs. It does not publish to GitHub or turn the proposed starter concepts into finalized canon.

- Whole work shifts are structured Missions. Individual stages become assigned Tasks after a work order is accepted. Tasks cannot be created independently by the player. The task directory points back to the parent assignment and never issues another base payout.
- WorkNet and VerseNet show the same visible opportunities. Hidden mystery Quests and Adventures require a contextual lead. Previously delivered invitations, started stories and earned rewards stay accessible in old saves.
- ATLAS opens an Aureline exploration view and Discovery Journal. Public places can be visited freely. Observations, unexplained objects, optional Quest offers, Adventure invitations and location keepsakes have different presentation rules. Some interactions require earlier observations, work knowledge, file knowledge or an established social connection.
- An authored Old Factory Ward Adventure has chapter metadata, persistent approach choices and an optional text-based cinematic scene. A separate field-response Adventure can emerge from exploring the platform, experiencing a repair incident, correcting it and preserving the report. Coordination and independent investigation expose different follow-up interactions. These scenes are marked as prototypes.
- Engineering is a continuing Journey with field-experience and accreditation chapters. Chapter records and the existing accreditation artifact are issued once. No final Journey completion state is created. Old Journey rewards remain preserved and cannot be reclaimed through the new chapter interface.
- HOMECRAFT has a separate Everyday life view. Cooking, tidying, rearranging and social time require manual interaction. Familiarity reduces steps and time; history and home arrangement persist. They do not issue XP, skill XP, work orders, Quests, or duplicate home-upgrade rewards. Browsing furnishings leads to the existing purchase system. Accumulated routine time advances simulation segments and cycles.
- The chronometer Quest accepts scanner investigation or a dialogue-based owner-account approach. Different interactions create the same scoped evidence receipt, so the assignment pays once.
- Career promotion additionally checks relevant skill proficiency and demonstrated professional experience, while retaining existing qualification and reputation pathways. Profession work contributes relevant skill practice. Existing rest, healthcare, housing and social reward safeguards remain in place.

No definitive generation probability, mastery curve, seven-day campaign, final content canon or new milestone currency schedule is asserted. Further content can extend the chapter, discovery, approach and branch definitions without changing the confirmed scope model.

Validation: `npm test --prefix frontend`; `npm run build --prefix frontend`. Regression checks cover discovery presentation and gating, assigned Tasks, daily-life independence and time, relationship directions, continuing Journey chapters, emergent branches, alternate Quest approaches, competency and old-save behavior.
