# Broad Street Vault Breach — Player Guide

Solve a connected investigation using Miraverse's desktop. You will read records, request a witness statement, compare evidence, and submit a supported report through WORKNET.

This guide explains the workflow without giving you the correct findings. Plan for roughly 20–30 minutes, depending on your reading and writing pace. There is no deadline.

## 1. Start the assignment

1. Open **WORKNET → Global Affairs**.
2. Select **Broad Street Vault Breach: Connected Investigation**.
3. Accept the assignment.
4. Read the briefing and select **I've read the briefing · begin investigation**.

You need existing **DGA/TRACE authorization and clearance 2**. Accepting the assignment does not grant credentials. Eligible players may also receive an opportunity dispatch in AureMail that leads to the assignment.

The case references are **CASE-2026-002 / FS-2026-00422**. A previously closed or paid version cannot be restarted as a fresh paid assignment.

## 2. Use the evidence notebook

Select **Open DGAOS evidence notebook** from the case workspace. The notebook lists the six sources and tracks which ones you have acquired.

Use a source's **Open original source** button to reach its reader. After collecting it, **Reopen source** takes you back to the same record. You can investigate in any order.

Reading a document does not automatically add it to your evidence. Use its explicit acquire or cite action, then check that the notebook shows **Acquired**. Your goal is **6 of 6 sources acquired**.

If you need a direction, select **Optional hint**. It suggests places to investigate without selecting your findings.

## 3. Collect the six sources

| App | Source | How to collect it |
| --- | --- | --- |
| VAULT | Access audit | Open the case folder, read the audit, and acquire it for the notebook. |
| VAULT | Facilities thermal log | Read the log and acquire it for the notebook. |
| DGAOS | EV-0010 metallurgy findings | Open the original laboratory record from the notebook and acquire it. |
| DGAOS | EV-0011 DNA findings | Open the original laboratory record from the notebook and acquire it. |
| AureMail | Mateo Cruz's clarification | Request the statement, read the correspondence, and add the statement to the notebook. |
| VerseNet | First Federal public facilities notice | Search for **First Federal maintenance**, open the notice, and cite it in the case. |

### VAULT: establish the record

Select **Open case folder in VAULT**. The folder contains the briefing, checklist, access audit, and thermal log.

Read the audit and thermal log carefully. Keep track of the recorded events, their sequence, and what each system actually measured. Select **Acquire source for case notebook** for each source.

### DGAOS: compare the laboratory findings

Open EV-0010 and EV-0011 through the evidence notebook. Read each finding and its limitations before acquiring it.

Keep laboratory observations separate from your interpretation. Ask what each comparison supports and what questions it leaves unanswered.

### AureMail: request clarification

In the notebook, select **Request witness clarification** for the guard's statement. Read Mateo Cruz's recorded reply in AureMail and use the statement's acquire action.

Requesting it again reopens the existing correspondence. You do not need to send repeated requests or compose a free-form message to progress.

### VerseNet: consult the public notice

Search **First Federal maintenance** in VerseNet and open the fixed First Federal facilities notice. Its in-world address is `https://firstfederal.aure/maintenance`.

Select **Cite this public page in Broad Street case**. This adds the source to the case; you will still select it beside any finding it supports in your report.

The notice is fictional content inside VerseNet. No real internet research is required. Private case evidence is accessed through the case's own apps and links.

## 4. Write your report in WORKNET

Return to WORKNET using **Open report in WORKNET** in the notebook.

1. Choose one structured finding for each of the three questions.
2. Select the acquired sources that support each finding.
3. Write your explanation in the formatted report editor.
4. Select **Submit report for evidence review**.

Your explanation needs at least **80 characters of your own writing**. Generated outline headings and `[Your findings]` placeholders do not count. An outline is a starting point: replace its placeholders with your reasoning.

A useful report explains the sequence supported by the records, connects each conclusion to its evidence, and identifies remaining uncertainty. Write in your own words. Review checks your structured findings and citations, plus the explanation length; it does not use AI or keyword matching to grade your prose.

Cite sources separately for each finding. A source being acquired does not automatically make it relevant to every question. Avoid selecting every citation just to fill the list.

## 5. Read feedback and revise

If review requests changes, read each feedback item. It may identify missing evidence, an unsupported finding, insufficient citations, unrelated citations, or an explanation that is too short.

Reopen the relevant sources, adjust your findings or citations, and submit again. Revisions are unlimited and carry no rating or reward penalty.

Submitted versions remain available in the report history. Editing an accepted draft requires another review before finalization. If you restore an earlier accepted draft, submit it again to restore its acceptance receipt.

Report acceptance means the investigation is supported by the selected evidence. It is not a criminal verdict.

## 6. Finalize and collect compensation

When you see **Evidence review accepted**, use WORKNET's compensation/finalization button to close the work order.

- **Reward:** 300 credits and 150 XP.
- **Bits:** none.
- **Finalization cost:** 10 stamina.
- **Payment:** once for the assignment.

Reading sources, requesting statements, saving drafts, and passing review do not themselves pay the reward. Reopening a completed case or repeating a submission does not pay again.

## Saving and returning later

The case uses Miraverse's existing saves. Your acquired evidence, witness correspondence, formatted draft, findings, citations, and submitted reviews persist when you close apps or reload. The authored case materials work offline once the game is available locally; Python is not required during play.

Return to the same WORKNET assignment to continue. Keep the same player save and browser profile when playing on localhost. Do not clear browser site data to troubleshoot progress: it can remove local saves.

## Troubleshooting

| What you see | What to check |
| --- | --- |
| Existing case access required | Check DGA/TRACE authorization and clearance 2. The assignment cannot issue them. |
| Sources cannot be acquired yet | Accept the assignment and acknowledge its briefing first. |
| A source is still marked Not acquired | Reopen its original reader and use the acquire/cite button. Reading alone is insufficient. |
| The guard's statement is missing | Use Request witness clarification, read the existing AureMail exchange, and acquire the statement. |
| Review asks for more writing despite an outline | Add at least 80 characters of your own explanation. Headings and placeholders are excluded. |
| Review rejects citations | Check that each citation is acquired, belongs to this case, and supports that particular finding. Follow the feedback for missing support. |
| An earlier report passed, but finalization is blocked after editing | Submit the current draft for review again, including after undoing edits. |
| Review passed but compensation is unavailable | Check the work-order status and that you have 10 stamina. Payment requires finalization. |
| The case was completed in an older save | The old completion is preserved; it cannot become another paid assignment. |
| Review reports a different content version | Keep the save. The work is preserved, but automatic review is unavailable for that version; report the mismatch for support. |
